# AutomateCodeLab

Practical, no-framework-magic coding tutorials — you see exactly how things work, not just which library to import.

### 🚩 Flagship: [Agentic AI, Unpacked](https://github.com/AutomateCodeLab/AgenticAI-Unpacked)

A 6-episode YouTube series that builds an AI agent from raw API calls to a production-safe system — no frameworks, every line explained.

| Ep | Topic | Big idea |
|----|-------|----------|
| 1 | What Is an AI Agent? | The agent loop: plan → act → observe → repeat |
| 2 | Build One From Scratch | An agent is a loop + tools, ~60 lines |
| 3 | Real Tools | Search / files / GitHub / calculator + guardrails |
| 4 | Multi-Agent Team | Orchestrator-workers — agents as tools for agents |
| 5 | Agent Memory | Short/long-term/semantic memory, RAG from scratch |
| 6 | Guardrails & Safety | Human approval, prompt-injection defense, kill switch |

Every episode ships with tested, runnable code and a full README — clone it and run it in minutes.
